## 一、口径定义

| 名称 | 公式 | 用途 |
|---|---|---|
| **官方口径**（`kaggle_score`） | `0.5×Macro-F1(pred_emotion) + 0.3×冲突准确率 + 0.2×一致特异度` | Kaggle 榜分口径，**排名以此为准** |
| **训练口径**（`local_score_present`） | `0.5×Macro-F1 + 0.3×冲突召回 + 0.2×一致特异度` | 早期实验为对齐课程基线而用，**不罚误报** |

- 验证集：666 条，真冲突 74 条（11.1%），一致样本 592 条
- 冲突准确率 = (TP+TN)/N；冲突召回 = TP/(TP+FN)；一致特异度 = TN/(TN+FP)
- `conflict_f1 = 2·TP / (2·TP + FP + FN + invalid_positive)`，分母含「把冲突判成无效值」的样本，**不能用 TP/FP/FN 手算替代**
