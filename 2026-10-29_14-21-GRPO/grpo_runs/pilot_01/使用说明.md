## 怎么用

**方式一：直接当 PEFT 适配器加载（推荐，省 11.4GB 磁盘）**

```python
from transformers import Qwen2_5OmniThinkerForConditionalGeneration
from peft import PeftModel

base = Qwen2_5OmniThinkerForConditionalGeneration.from_pretrained(
    r"MM-Emotion-Combined-SFT-20261026/base_model",
    dtype="bfloat16", device_map="auto")
model = PeftModel.from_pretrained(base, r"GRPO_pilot01_step50/step_0050")
model.eval()
```

**方式二：合并成独立完整模型（约 11.4GB，之后不再依赖 adapter）**

```python
merged = model.merge_and_unload()
merged.save_pretrained(r"D:\Qwen2.5-Omni-3B-GRPO-step50")
```

**方式三：复评**

用项目里 `2026-10-29_14-21-GRPO/train_grpo.py` 相同的评测流程，把 `--adapter` 指向本目录的 `step_0050` 即可，
预期得到 综合评分 0.8934 / 情绪 Macro-F1 0.9510 / 冲突召回 0.7838 / 无冲突特异度 0.9139。

## 注意

- 适配器必须搭配**原始** Qwen2.5-Omni-3B 基座，不能搭配已经贴过 SFT 适配器的模型（会重复叠加）。
- 本目录只含最优 step_0050。其余 5 个检查点（step_0100…step_0300）未归档，需要时重跑对应步数即可复现。
